# Customer Sentiment Analysis Demo

## About the project

This project is a small, offline demonstration of customer sentiment analysis. It lets a user enter an e-commerce product review and see the sentiment predicted by the demo: **Positive**, **Neutral**, or **Negative**.

The idea is that businesses could use sentiment analysis to help sort customer comments and find possible complaints more quickly. A person should still read the review and decide what action to take.

## How to use the demo

1. Download `Review Sentiment.html`.
2. Open the file in a modern web browser, such as Chrome or Edge.
3. Enter a product review in the text box.
4. Select the button to analyse the review.
5. Read the predicted sentiment.

The demo runs locally in the browser. It does not require an account or send the review text to a server.

## How it works

The demo uses a machine-learning approach to look for patterns in review text and assign a sentiment label. In the project experiment, review text was converted into numerical features using TF-IDF, then a Logistic Regression model was used to predict sentiment.

The labels in the experiment were based on star ratings: 1–2 stars were labelled Negative, 3 stars Neutral, and 4–5 stars Positive.

## Limitations

This is a student prototype, not a production system. Predictions can be wrong, especially when a review contains mixed opinions, sarcasm, unusual wording, slang, or context the model has not seen. The demo has not been validated on live social-media comments. Its results should not be treated as verified facts about a product or customer.

## Data source

The experiment used the **All Beauty 5-core** subset of Amazon Review Data (2018), provided by the UC San Diego research project:

Ni, J., Li, J. and McAuley, J. (2019) ‘Justifying recommendations using distantly-labeled reviews and fine-grained aspects’, *Proceedings of the 2019 Conference on Empirical Methods in Natural Language Processing and the 9th International Joint Conference on Natural Language Processing (EMNLP-IJCNLP)*, pp. 188–197. Available at: https://doi.org/10.18653/v1/D19-信

Dataset information: https://nijianmo.github.io/amazon/index.html
